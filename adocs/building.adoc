= Building Redlinks

To build Redlinks, you can use the `redc` command from the command line. Make sure you have the Red compiler installed and available in your PATH.

== Here's how you can build Redlinks:
  
    * redc build.red --cleanup (this will clean up any previous build artifacts before building)
    * redc build.red --release (this will build Redlinks in release mode, optimizing for performance)
    * redc build.red --auto    (auto-detects the best build options for your system)
